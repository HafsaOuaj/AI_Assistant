
# 🤖 AI Assistant for Data Science Projects

Welcome to the **AI Assistant** project! In this series, we are developing an **AI assistant** that utilizes **Streamlit**, **LangChain**, **OpenAI**, and **Pinecone** to assist with various stages of your **data science projects**. The assistant streamlines tasks such as **Exploratory Data Analysis (EDA)**, **model selection**, **prediction**, and even provides an interactive **chatbox** for real-time assistance.

---

## ⚙️ Prerequisites

Before using the AI Assistant, make sure you have the following dependencies installed on your machine:

- ![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) **Python** (version 3.8 or higher)
- ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white) **Streamlit**: A framework for building interactive web apps.
- ![Pandas](https://img.shields.io/badge/Pandas-150458?style=for-the-badge&logo=pandas&logoColor=white) **Pandas**: Powerful library for data manipulation and analysis in Python.
- ![OpenAI](https://img.shields.io/badge/OpenAI-412991?style=for-the-badge&logo=openai&logoColor=white) **OpenAI API Key**: Required to access OpenAI's language models (ensure to replace `apikey` in the script with your actual key).
- ![dotenv](https://img.shields.io/badge/dotenv-ECD53F?style=for-the-badge&logo=dotenv&logoColor=black) **dotenv**: For managing environment variables.
- ![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white) **Docker**: To containerize the application for easier deployment.
- ![Poetry](https://img.shields.io/badge/Poetry-60A5FA?style=for-the-badge&logo=poetry&logoColor=white) **Poetry**: For dependency management and packaging in Python.

## 🚀 How to Run

To get started with the AI Assistant:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/ai-assistant-for-data-science-projects.git
   ```

2. **Install dependencies**:
   Using Poetry for dependency management:
   ```bash
   poetry install
   ```

3. **Set up environment variables**:
   Create a `.env` file in the root directory and add your **OpenAI API key**:
   ```plaintext
   OPENAI_API_KEY=your_api_key_here
   ```

4. **Run the app**:
   Launch the Streamlit application:
   ```bash
   streamlit run app.py
   ```

## 🧠 Features

- **Exploratory Data Analysis (EDA)**: Automatically generate insights and visualizations for your dataset.
- **Model Selection**: Get recommendations for the most suitable machine learning models based on the dataset characteristics.
- **Predictions**: Make predictions using selected models and datasets.
- **Interactive Chatbox**: Chat with the assistant for real-time queries, analysis, and recommendations.
